# v1 Balance Notes

目標：讓一局人類實際遊玩大約 15 分鐘內結束，同時常態能看到 `細胞 -> 組織 -> 器官` 的推進。

## v1 核心規則

- 每回合可放 `3` 張素材、進化 `2` 次。
- 實驗區上限 `10`，戰場不限張數。
- 起始實驗區放入 `胺基酸` 與 `磷脂質` 各 `1` 張，避免前期空轉。
- 一般攻擊先打前線；只有少數帶 `直擊` 的卡能越線打本體。
- 本體護盾上限 `12`，`藥物` 與階段獎勵都會補本體護盾。

## v1 配方簡化方向

- `細胞核 = DNA + 蛋白質`
- `粒線體 = 細胞膜 + DNA`
- `上皮細胞 = 細胞四核心`
- `組織 = 細胞 + 蛋白質`
- `器官 = 組織 + 專精素材`
- `系統 = 同名器官 x2`

## v1 節奏調整

- 移除 `染色體` 死路配方，避免 AI 與支援卡浪費回合。
- 直接部署的特殊戰鬥卡下修為干擾節奏，不再是主要勝利手段。
- AI 會保留有培養價值的單位，不再無腦全攻。
- `定序儀` / `CRISPR` / 回收類效果會沿配方往下拆缺件，支援重複升階。
