# Biology Cards MVP 設計稿

## 目標

這份文件把 [setting.md](/Users/jordan/Desktop/my_website/biology_cards/setting.md) 的方向整理成第一版可執行規格，並同步對應到 [mvp-cards.json](/Users/jordan/Desktop/my_website/biology_cards/data/mvp-cards.json)，讓後續可以直接進入資料建模、原型製作與數值平衡。

MVP 先聚焦兩條主線：

- 人類構築線：從分子、胞器一路進化到細胞、組織、器官、系統、個體。
- 病原特例線：細菌與病毒直接作為特殊戰鬥卡登場，不走進化流程。

## 核心規則

- 卡牌先維持四大類：`物品`、`疾病`、`角色`、`結構`。
- 只有 `結構` 類卡可以形成戰場上的主體。
- `物品`、`疾病`、`角色` 都是輔助卡，不直接進場攻擊。
- 結構卡再細分成九個階層：`基礎分子`、`分子`、`胞器`、`細胞`、`組織`、`器官`、`系統`、`個體`、`特殊`。
- `細胞` 以上的結構卡才具備完整戰鬥能力；`基礎分子`、`分子`、`胞器` 主要是進化素材。
- 為了讓牌局節奏可控，器官到系統採用「濃縮配方」，是遊戲化抽象，不追求真實生物比例。

## 進化流程

### A. 分子與胞器裝配

| 輸出 | 素材 |
| --- | --- |
| DNA | 腺嘌呤(A) + 胸腺嘧啶(T)；或 胞嘧啶(C) + 鳥糞嘌呤(G) |
| RNA | 尿嘧啶(U) + 任意一張 DNA 鹼基 |
| 蛋白質 | 胺基酸 x2 |
| 細胞膜 | 磷脂質 x2 |
| 染色體 | DNA + 蛋白質 |
| 核糖體 | RNA + 蛋白質 |
| 細胞核 | DNA + RNA + 蛋白質 |
| 粒線體 | 細胞膜 + DNA + 蛋白質 |

說明：

- `基礎分子`、`分子`、`胞器` 都放在實驗區，主要用於組裝。
- 這些卡預設不作為主要戰鬥單位。

### B. 細胞到個體的主進化線

| 輸出 | 素材 |
| --- | --- |
| 真核細胞 | 細胞膜 + 細胞核 + 核糖體 + 粒線體 |
| 上皮細胞 | 真核細胞 + 蛋白質 |
| 心肌細胞 | 真核細胞 + 粒線體 |
| 神經細胞 | 真核細胞 + RNA |
| 肺泡細胞 | 真核細胞 + 細胞膜 |
| 上皮組織 | 上皮細胞 x2 |
| 心肌組織 | 心肌細胞 x2 |
| 神經組織 | 神經細胞 x2 |
| 肺泡組織 | 肺泡細胞 x2 |
| 皮膚 | 上皮組織 x2 |
| 心臟 | 心肌組織 x2 |
| 大腦 | 神經組織 x2 |
| 肺 | 肺泡組織 x2 |
| 外皮系統 | 皮膚 x2 |
| 循環系統 | 心臟 x2 |
| 神經系統 | 大腦 x2 |
| 呼吸系統 | 肺 x2 |
| 人類個體 | 外皮系統 + 循環系統 + 神經系統 + 呼吸系統 |

說明：

- `細胞` 以上進入戰場區，成為主要戰鬥單位。
- 每回合建議限制 1 次進化行動，避免連鎖爆發。
- 同名雙卡合成組織、器官、系統，規則簡單，便於前期測試。

### C. 特殊卡規則

| 卡名 | 規則 |
| --- | --- |
| 大腸桿菌 | 可直接登場，不可進化，對組織卡有額外壓力 |
| 金黃色葡萄球菌 | 可直接登場，不可進化，偏向持續感染與磨損 |
| 流感病毒 | 可直接登場，不可進化，對肺泡細胞、肺、呼吸系統有加成 |
| 冠狀病毒 | 可直接登場，不可進化，可干擾細胞升級與系統穩定度 |

## 輔助卡能力草案

### 1. 物品卡能力

| 卡名 | 能力草案 |
| --- | --- |
| 移液器 | 從棄牌區回收 1 張 `基礎分子` 或 `分子` 卡；若本回合立刻用於進化，該卡可視為萬用素材 |
| 離心機 | 檢視牌庫頂 3 張，選 1 張 `結構` 卡加入手牌，其餘置底 |
| PCR 儀 | 指定 1 張己方 `DNA` 或 `RNA`，生成 1 張複製品到手牌 |
| 定序儀 | 檢視牌庫頂 5 張，選 1 張 `結構` 或 `疾病` 卡加入手牌；也可公開對手 1 張蓋牌疾病 |
| 培養箱 | 指定 1 張己方 `細胞`，本回合不受首次傷害，且下一次 `細胞 -> 組織` 進化少消耗 1 張同名細胞 |
| CRISPR 試劑組 | 移除 1 個附著於己方結構的 `疾病` 效果，或將 1 張己方 `DNA/RNA` 重新指定為另一個合法進化素材 |

### 2. 疾病卡能力

| 卡名 | 能力草案 |
| --- | --- |
| 癌症 | 附著在 1 張 `細胞/組織/器官` 上；附著期間該卡不能進化，回合結束時承受持續傷害 |
| 流感 | 指定對手 1 張 `肺泡細胞/肺/呼吸系統`；其攻擊力下降，且下回合少 1 次額外支援機會 |
| 登革熱 | 指定對手 1 張 `器官/系統`；造成持續傷害，且本回合不能被角色卡回復 |
| 細菌感染 | 附著在 1 張 `組織/器官` 上；目標每次進化前需額外棄 1 張手牌，否則進化失敗 |
| 遺傳性突變 | 指定 1 張 `DNA/染色體/真核細胞`；其下一次進化需多消耗 1 張素材，否則進化取消 |

### 3. 角色卡能力

| 卡名 | 能力草案 |
| --- | --- |
| 醫師 | 進場時移除 1 個己方 `疾病` 效果，或回復 1 張 `細胞` 以上單位 |
| 生資工程師 | 檢視牌庫頂 4 張，依任意順序放回，並可抽取其中 1 張 `DNA/RNA/疾病` |
| 分子生物學家 | 每回合第一次進行 `基礎分子 -> 分子` 或 `分子 -> 胞器` 進化時，可少 1 張素材 |
| 實驗技術專員 | 你本回合打出的第一張 `物品` 卡結算後回到手牌，而非進入棄牌區 |
| 細胞培養師 | 你本回合新生成的 `細胞` 獲得護盾；若該細胞本回合再進化，額外抽 1 張牌 |

## 建議的 MVP 對戰節奏

1. 前期用 `物品` 與 `角色` 快速補齊分子和胞器。
2. 中期把 `真核細胞` 轉成專精細胞線，開始進場戰鬥。
3. 後期以 `器官`、`系統`、`個體` 爭奪場面優勢。
4. `疾病` 與 `特殊病原卡` 提供干擾，避免雙方只是直線堆疊。

## 下一步建議

- 補上每張卡的 `費用`、`攻擊`、`生命`、`稀有度`。
- 定義牌組限制，例如每副牌 30 張、同名卡最多 3 張。
- 把 `疾病` 與 `特殊病原卡` 的干擾效果拆成可程式化欄位，例如 `statusEffects`、`duration`、`targets`。
- 做一個最小可玩的網頁原型，先驗證進化節奏是否順。
